# 桥梁文化展示交互Web应用 - 产品需求文档

## 1. 产品概述
一个以"长河桥影"为品牌的桥梁文化展示交互应用,通过地图检索、3D模型展示、多媒体交互等方式,全方位呈现中国桥梁的历史文化、技术发展和人文故事。

**核心价值**: 将传统桥梁文化与现代交互技术结合,打造沉浸式的文化体验平台,服务于文化教育、旅游推广、技术科普等场景。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|----------|
| 访客用户 | 无需注册 | 浏览所有桥梁信息、查看地图、体验3D模型 |
| 研究者 | 申请认证 | 访问详细技术资料、下载模型数据(预留) |

### 2.2 功能模块
1. **首页**: 地图检索、桥梁列表、视角切换、分类筛选、技术发展时间轴
2. **桥梁详情页**: 3D模型展示、桥梁信息、历史变迁、交互控制

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 首页 | 品牌区 | 顶部显示"长河桥影"品牌标识,配合装饰性图案和动画 |
| 首页 | 地图检索区 | 中央展示中国地图,标注桥梁位置图标,支持缩放和平移 |
| 首页 | 桥梁列表 | 右侧显示桥梁名称列表,支持快速筛选和搜索 |
| 首页 | 视角控制 | 底部工具栏提供全局、局部、东部、南部四种视角切换 |
| 首页 | 分类筛选 | 底部桥梁分类图标(拱桥、梁桥、索桥、浮桥等) |
| 首页 | 技术发展轴 | 底部时间轴展示桥梁技术演变历程 |
| 桥梁详情页 | 交互展示区 | 左侧三态切换:场景图、粒子模型、3D模型 |
| 桥梁详情页 | 桥梁信息卡 | 右侧显示桥梁名称、地点、尺寸、年代、人文故事、历史变迁、关键技术 |
| 桥梁详情页 | 桥梁列表 | 右侧固定显示桥梁汇总列表,方便快速切换 |

## 3. 核心流程

### 3.1 用户浏览流程
用户进入首页 → 查看地图上的桥梁分布 → 选择视角或分类筛选 → 点击桥梁图标查看详情 → 在详情页体验三态模型切换 → 阅读桥梁文化和历史信息 → 返回首页继续探索

## 4. 用户界面设计

### 4.1 设计风格

**配色方案 - 莫兰迪色系与东方美学融合**
- **主色调**: 青灰色(#8B9A9B) - 象征古老桥梁的青石质感
- **辅助色**:
  - 暖米色(#D4C5B9) - 温润的古典气息
  - 朱砂红(#C8553D) - 传统中国红点缀
  - 墨灰色(#4A4A4A) - 水墨画般的沉稳
  - 青绿色(#7D9D9C) - 江南水乡的意境
- **背景色**: 米白色(#F5F1ED) - 宣纸般的质感

**字体选择**
- 标题: "思源宋体"或"Noto Serif SC" - 传统书法韵味
- 正文: "思源黑体"或"Noto Sans SC" - 清晰易读
- 数字: "DM Serif Display" - 优雅的数据展示

**布局风格**
- 沉浸式全屏布局,减少视觉干扰
- 卡片式信息展示,配合水墨晕染效果
- 非对称构图,体现东方美学的留白意境
- 装饰性元素采用传统纹样(云纹、水波纹)

**交互动效**
- 水墨晕染过渡效果
- 桥梁图标呼吸动画
- 模型切换淡入淡出
- 列表项悬停涟漪效果
- 页面加载时的卷轴展开动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 首页 | 品牌区 | 顶部居中,书法字体标题,配合云纹装饰,背景渐变透明,高度80px |
| 首页 | 地图检索区 | 中央占据主体区域,浅色地图背景,桥梁图标采用古桥简笔画风格,悬停时发光效果 |
| 首页 | 桥梁列表 | 右侧固定宽度300px,半透明背景,列表项带序号和名称,悬停时左侧出现朱砂红竖线 |
| 首页 | 底部工具栏 | 高度100px,图标采用线框风格,悬停时填充颜色并放大,分组显示 |
| 桥梁详情页 | 交互展示区 | 左侧60%宽度,三态按钮组在顶部,场景图为实景照片,粒子模型使用动态粒子效果,3D模型支持旋转缩放 |
| 桥梁详情页 | 桥梁信息卡 | 右侧40%宽度,卡片式布局,信息分段展示,年代使用时间轴样式,关键技术用图标表示 |
| 桥梁详情页 | 桥梁列表 | 右侧固定,宽度与首页一致,保持交互一致性 |

### 4.3 响应式设计
- 采用桌面优先设计,针对大屏(1920x1080及以上)优化
- 保持主要功能在中等屏幕(1366x768)可用
- 触摸设备支持手势操作(地图缩放、模型旋转)

### 4.4 3D场景指导

**环境与氛围**
- HDRI: 柔和的晨曦或黄昏光照,营造温暖的文化氛围
- 背景: 水墨风格的渐变背景,配合远山剪影
- 粒子效果: 模拟水流、烟雾等自然元素

**光照设置**
- 主光源: 柔和的暖光(3000K),模拟自然光
- 辅光: 冷色调补充光,增强立体感
- 环境光: 低强度,避免过曝

**相机设置**
- 初始视角: 45度俯视,展示桥梁全貌
- 运动控制: 支持轨道控制器,限制缩放范围
- 动画: 平滑过渡,缓入缓出

**构图与焦点**
- 桥梁模型居中,周围留白
- 辅助元素(水面、山石)衬托主体
- 引导线指向桥梁关键结构

**交互与动画**
- 模型加载: 渐进式显现,配合粒子消散效果
- 视角切换: 相机平滑飞行至预设位置
- 热点标注: 点击桥梁关键部位显示技术说明

**后处理效果**
- 抗锯齿: FXAA或SMAA
- 色调映射: ACES Filmic,增强画面质感
- 景深: 轻微模糊背景,突出主体

**资源与性能**
- 模型格式: GLTF/GLB,优化面数(单桥<10万面)
- 纹理尺寸: 主纹理2K,辅助纹理1K
- 目标帧率: 60fps,低端设备降级方案

## 5. 数据需求

### 5.1 桥梁数据结构
每个桥梁需包含以下信息:
- 基本信息: ID、名称、别名、地点(省份、城市、经纬度)
- 技术参数: 类型、长度、宽度、高度、跨度、建造年代、修缮记录
- 文化信息: 人文故事、历史变迁、保护级别、旅游景点
- 媒体资源: 场景图片、3D模型、粒子模型、线图、历史照片
- 关键技术: 结构特点、材料工艺、创新点

### 5.2 分类数据
- 桥梁类型: 拱桥、梁桥、索桥、浮桥、廊桥、其他
- 视角分类: 全局视图、局部特写、东部区域、南部区域
- 技术时期: 古代(隋唐以前)、中古(隋唐至宋元)、近代(明清至民国)、现代(新中国成立后)
